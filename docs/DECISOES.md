# Registro de decisões

## Confirmadas
- Objetivo: priorizar oportunidades abertas com explicação, usando dados reais do desafio.
- Construção modular antes de sofisticar infraestrutura.
- Usuário escolheu recriar via Streamlit no Antigravity IDE.
- Este pacote serve de contexto/entrada para recriação, não entrega código pronto.
- Política de scoring `heuristic-v1` aprovada pelo usuário em 20/10/2026: base 10; Engaging +60; Prospecting +30; score heurístico, não probabilidade; preço de catálogo somente como desempate; campos ausentes geram aviso sem penalidade; sem uso de resultados futuros.
