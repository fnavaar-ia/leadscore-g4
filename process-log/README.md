# Process log — manter durante a construção

Este kit foi produzido com assistência de IA para organizar contexto, PRD, dados e prompts. A implementação no IDE ainda não foi realizada neste pacote. Não registrar Antigravity como ferramenta já utilizada na construção do app antes de usá-la de fato.

Para cada módulo, criar uma entrada baseada em TEMPLATE.md. Preservar prompts e saídas relevantes e evidências de teste reais. Capturas e exports não devem conter credenciais ou dados privados desnecessários.

Decisão humana já observada: exigir PRD modular antes do scoring; escolher recriação em Streamlit. Não inventar outras intervenções humanas. Erros analíticos da fase anterior e suas correções constam na seção 4.3 do PRD.
